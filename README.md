# OCR 藍牙鍵盤

以手機相機或相簿照片進行 PP-OCRv5 辨識，再選取文字，透過 Android Bluetooth HID 鍵盤輸入到電腦目前的游標位置。適合將處方照片中的代碼快速登打到電腦欄位。

## 使用方式

1. 在手機安裝並開啟 App，按「配對電腦」。
2. 允許附近裝置權限，並允許手機進入可被搜尋狀態。
3. 在電腦的藍牙設定中新增並配對「PhotoBarcode Keyboard」。
4. 回到 App，按「連線電腦」並選擇已配對的電腦。
5. 在電腦點選要輸入的欄位；在 App 拍照或選擇照片，開啟 OCR 文字。
6. 長按並框選文字，按「發送選取文字」。也可以在首頁手動輸入後按「發送到電腦」。

## 支援範圍與注意事項

- 藍牙 HID Device 需要 Android 9（API 28）或更新版本，且手機廠商的藍牙堆疊必須支援 HID Device。
- 電腦需支援 Bluetooth HID 鍵盤。電腦和手機需先完成藍牙配對，且送出前要在電腦選好目標欄位。
- 目前鍵盤映射支援英文字母、數字、空格及常見 ASCII 符號；不支援中文、換行或其他 Unicode 字元。若選取文字含不支援字元，整段不會發送。
- 鍵盤符號依美式鍵盤配置映射；不同電腦鍵盤配置可能造成符號不同。健保碼等英數代碼較適合此輸入方式。
- 每次傳送都由使用者按鈕觸發。OCR 和輸入文字不會由 App 自動傳送；送出前請核對 OCR 結果及電腦目前的焦點欄位。
- App 保留 PaddleOCR PP-OCRv5 與 OpenCV 原生程式庫初始化流程。
